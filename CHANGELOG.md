# Changelog

## 0.3.0a1

This prerelease establishes the GA-track foundation:

- typed availability, modality, native-unit, and collection-manifest semantics;
- capability-aware PTU eligibility and conservative capacity evidence;
- layered public, contract, Marketplace, override, and actual-cost pricing;
- official Azure Retail API and Foundry provider-page pricing sources;
- actionable aggregate insights with evidence, confidence, action, and verification;
- operational, optimization, and full assessment modes;
- contentless SDK/OpenTelemetry/Application Insights/import telemetry;
- workload, task, PTU, HTML, JSON, SARIF, and CLI contract hardening;
- offline analysis, package-data validation, privacy controls, and sanitized configuration.

This is not yet the `1.0.0` GA release. Remaining release gates are validation,
supportability, and release-operations hardening.
